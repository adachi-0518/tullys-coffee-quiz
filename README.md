# ☕ タリーズ コーヒー豆診断

5つの2択質問に答えるだけで、タリーズコーヒーの定番コーヒー豆（全17種）の中から、あなたにぴったりの一品をおすすめするWebアプリです。

**👉 診断してみる: https://adachi-0518.github.io/tullys-coffee-quiz/**

## 特徴

- 質問はすべて2択・約30秒で診断完了
- 豆のデータ（説明・原産地・すっきり感/ボディの10段階評価・おすすめの飲み方・価格）はタリーズ公式サイト調べ（2026年7月時点）
- 結果画面から公式の商品ページへジャンプ可能
- スマホ対応

## 使った技術

- HTML / CSS / JavaScript（フレームワーク・ビルド不要の静的サイト）
- ホスティング: GitHub Pages

## 診断の仕組み

回答するたびに各豆へポイントが加算され、合計点が最も高い豆が結果になります。配点は公式サイトの「すっきり感」「ボディ」の数値や「おすすめの飲み方」タグから算出しています。詳しくは [script.js](script.js) の `BEANS` と `QUESTIONS` を参照してください。

## 注意

- 店舗スタッフが個人的に制作したアプリであり、タリーズコーヒージャパン公式のものではありません
- 価格・取扱ラインナップは変更になる場合があります
